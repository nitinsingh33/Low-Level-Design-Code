# Parking Lot System

## Problem Statement

Design and implement a parking lot management system that supports different vehicle types, multiple parking floors and different parking spot sizes.

## Requirements

1. The parking lot has multiple floors.
2. Each floor contains multiple parking spots.
3. Support Motorcycle, Car and Truck.
4. Each parking spot can accommodate compatible vehicles.
5. Assign an available spot when a vehicle enters.
6. Generate a parking ticket.
7. Allow vehicles to exit and calculate parking fees.
8. Release the spot after payment.

## Expected Classes

Identify the necessary classes yourself.

## Expected Functionality

- `parkVehicle()`
- `unparkVehicle()`
- `findAvailableSpot()`
- `calculateFee()`

## Interview Constraints

- Use OOP principles.
- Follow appropriate SOLID principles.
- Avoid unnecessary complexity.
- Handle unavailable parking spots.
- Keep the design extensible.

## Practice Rules

- First attempt: Design independently without looking at solutions.
- Draw the class diagram before coding.
- Implement the complete working solution.
- Test normal and edge cases.
- Explain your design decisions as if you were in an interview.
