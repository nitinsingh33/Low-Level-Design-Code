## How I Practice

For every LLD problem:

1. Understand the requirements.
2. Identify classes and their responsibilities.
3. Define relationships between classes.
4. Draw a UML class diagram.
5. Implement the solution in C++.
6. Test different scenarios and edge cases.
7. Review the design and explain the decisions.

## Coding Standards

- Language: C++17
- Write clean, readable and modular code.
- Follow appropriate OOP and SOLID principles.
- Prefer composition over unnecessary inheritance.
- Use appropriate memory management.
- Avoid overengineering.
- Focus on working implementations rather than theoretical complexity.

## Scope
